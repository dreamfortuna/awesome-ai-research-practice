# 记录模板

| 模板 | 用途 | 建议保存位置 |
| --- | --- | --- |
| [资源卡](resource-card.md) | 外部项目或具体技能的来源与评价 | `resources/` |
| [实践笔记](experience-note.md) | 一次真实任务及复盘 | `notes/` |
| [工作流](workflow.md) | 可重复执行的科研流程 | `workflows/` |
| [技能草稿](skill-draft.md) | 从工作流提炼 Agent Skill | `skills/<skill-name>/SKILL.md` |

复制后替换占位内容并更新所属索引。技能草稿放在模板目录，不作为可安装技能发布。
